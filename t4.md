## decisoes:
- grupo novo que chega com gente na fila vai direto para o fim da fila (nao fura a fila)
- mesa so pode ser ocupada se estiver livre e com os 4 pratos, mesmo que o grupo seja de 1 pessoa
- ao sentar, os pratos excedentes (4 - pessoas) voltam para a pilha
- repor pratos tambem arruma as mesas livres incompletas e chama a fila
- ao abrir: cada mesa recebe 4 pratos e a pilha comeca vazia (so entram pratos devolvidos pelas mesas ou repostos pelo funcionario)
- grupo com mais de 4 pessoas ocupa varias mesas (4 por mesa, a ultima com o resto), o que sobrar vai para a fila com uma senha
- grupo grande atendido em parte continua na fila com a mesma senha e a quantidade de pessoas atualizada
- cada ocupacao de mesa gera uma comanda nova (grupo em varias mesas = uma comanda por mesa)
- desistir da fila: passa os grupos para uma fila auxiliar descartando o da senha, depois devolve
- sem variaveis globais: tudo fica dentro de Restaurante, passado por ponteiro
- todas as structs alocadas com malloc e liberadas com free no final
- abrir o restaurante de novo libera tudo que existia antes

## structs:
Prato prato {           (pilha.h)
    int id
    Prato* prox
}

Pilha pilha {           (pilha.h)
    Prato* topo
    int qtd
}

Grupo grupo {           (fila.h)
    int senha
    int qtd_pessoas     (pessoas que ainda esperam)
    Grupo* prox
}

Fila fila {             (fila.h)
    Grupo* inicio
    Grupo* fim
    int qtd_grupos
    int qtd_pessoas     (total de pessoas na fila)
}

Mesa mesa {             (mesa.h)
    int numero
    int ocupada         (0 livre, 1 ocupada)
    int qtd_pessoas     (0 a 4)
    int comanda         (0 se livre)
    int qtd_pratos      (0 a 4)
}

Restaurante restaurante {   (restaurante.h)
    Mesa** mesas        (matriz linhas x colunas)
    int linhas
    int colunas
    Pilha* pratos
    Fila* espera
    int prox_senha
    int prox_comanda
    int prox_id_prato
    int aberto          (0 ate usar a opcao 1)
}

## menu:
1) Abrir restaurante: informar quantidade de mesas (linhas e colunas da matriz) e arrumar as mesas completas.
2) Chegar (grupo de) clientes ao restaurante: implica em ocupar mesa se há disponibilidade ou ir para fila de espera.
3) Finalizar refeição/liberar mesa: sempre que uma mesa é liberada, a mesa completa é arrumada (4 pratos), clientes são
chamados da fila de espera (se houver) e a quantidade de pratos é ajustada na mesa (tirar pratos excedentes da mesa, se
necessário, e recolocá-los na pilha).
4) Desistir de esperar: sair da fila de espera.
5) Repor pratos: adicionar pratos na pilha.
6) Imprimir pilha de pratos, fila de espera e ocupação das mesas:
6.1) Ocupação das mesas: número da mesa e quantidade de pessoas que ocupam a mesa. O usuário pode pesquisar
por número de mesa ou então consultar todas as mesas;
6.2) Fila de espera: quantos grupos estão na fila de espera, e quantas pessoas aguardam na fila de espera;
6.3) Pilha de pratos: quantos pratos existem na pilha de pratos.
0) Sair: liberar memoria e encerrar.
